# API Reference

See the following endpoints:

- `POST /api/chat/send` — forwards to TS backend
- `POST /api/files/upload` — file upload
- `POST /api/audio/transcribe` — forwards to Python backend
- `POST /api/kernel/send` — kernel orchestrator
- `GET/POST /api/wallet/points` — wallet demo
- `POST /api/auth/[...nextauth]` — NextAuth
