# NeuroEdge — Complete Frontend Build

This is a full frontend scaffold for NeuroEdge (React + Vite). It includes contexts, pages, components, PWA manifest, and simple mock APIs.

Install & run:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

Notes:
- Default theme: light (white). Toggle with the theme button in the header.
- Founder can upload assets via AssetUploader (stores locally in IndexedDB).
- To deploy to Vercel ensure Node 22.x is set in package.json engines.
